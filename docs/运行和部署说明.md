# 运行和部署说明

## 本地运行

推荐方式：

1. 双击 `启动本地预览.command`
2. 第一次运行时，脚本会自动安装 React + Vite 依赖
3. 等待浏览器自动打开
4. 点击作品首页的“进入”
5. 点击右上角 `全屏`，或按键盘 `F`，进入录屏用全屏模式

如果系统阻止脚本运行，可以打开终端进入本文件夹后运行：

```bash
npm install
npm run dev
```

然后在浏览器打开：

```text
http://127.0.0.1:8787
```

## 构建检查

上线或交给别人前，建议先运行：

```bash
npm run build
```

构建成功后会生成 `dist/` 文件夹。

## 线上部署

这个文件夹是 React + Vite 项目，可以直接部署到静态托管平台。

不需要自己购买服务器。Netlify、Vercel、Cloudflare Pages 都可以托管这种静态网页，并提供一个可分享的网址。以后如果需要正式域名，再把域名绑定到托管平台即可。

Netlify 推荐流程：

1. 登录 Netlify
2. 选择 Add new site
3. 连接 GitHub 仓库，或选择手动部署
4. 构建命令使用 `npm run build`
5. 发布目录使用 `dist`
6. 等待部署完成，复制生成的网址

## 现场展览

当前版本可以在 3-5 台电脑同时打开线上网址，各自独立互动。

如果只做本地测试，可以每台电脑各自运行本文件夹。正式展览前建议再做一次现场网络、全屏、音量和录屏测试。

如果现场网络不稳定，建议后续增加离线展览版本：

- 一台电脑作为本地服务器
- 其他电脑连接同一现场 Wi-Fi
- 打开局域网地址观看

## 注意事项

- 不要移动或重命名 `public/media/` 里的文件，否则网页会找不到视频。
- 原始 4K 素材不需要放进这个文件夹。
- 当前版本优先适配电脑横屏，不建议作为手机竖屏版本使用。
- 全屏必须由观众点击按钮或按键触发，浏览器不允许网页自动进入全屏。
