# 一个重新会疼的世界 - 线上电脑网页版

这是作品的电脑端互动影像原型，当前已迁移为 React + Vite 结构。文件夹内包含网页工程、交互逻辑、压缩后的视频素材和运行说明，不依赖原始素材文件夹。

## 文件结构

- `index.html`：Vite 页面入口
- `src/main.jsx`：React 互动影像主程序
- `src/storyConfig.js`：章节、素材、热点、变量和报告配置
- `src/styles.css`：视觉样式
- `public/media/`：网页播放用视频素材
- `package.json`：开发和构建脚本
- `docs/`：素材选择和运行部署说明
- `netlify.toml`：Netlify 部署配置
- `启动本地预览.command`：本地预览启动脚本

## 本地预览

优先双击 `启动本地预览.command`，脚本会自动安装依赖并打开本地预览地址。

也可以在终端里运行：

```bash
npm install
npm run dev
```

然后打开：

```text
http://127.0.0.1:8787
```

进入作品后，右上角有 `全屏` 按钮，也可以按键盘 `F` 进入或退出全屏，方便后续录屏。

## 当前交互

- 移动鼠标会出现扫描框和识别文字。
- 画面中出现发光热点时，可以直接点击画面触发路径。
- 如果观众停留不动，系统会按“默认归档”继续推进。
- 疼痛、速度、凝视三个变量会影响画面气质和最终报告。
- 结尾会生成一份“身体记忆报告”。

## 线上分享

这个文件夹可以部署到 Netlify、Vercel 或 Cloudflare Pages。部署时执行 `npm run build`，发布 `dist/` 目录。

不需要先购买服务器或域名。后续可以先使用平台提供的免费网址，等作品定稿后再绑定自己的域名。

## 展览提醒

第一版优先用于电脑端线上分享。后续如果进入现场展览，应再做离线展览包和 3-5 台电脑并发测试。
